# Frontend

React SPA: Vite, TypeScript (strict), Tailwind v4, shadcn/ui, TanStack Router/Query/Form, Zod. Lint with oxlint, format with oxfmt, tests with Vitest. Design rules: `../DESIGN.md`.

From the repo root:

- `make frontend-dev` installs and starts Vite on http://localhost:5173; `/api` is proxied to Django on :8000.
- `make frontend-check` runs lint, typecheck and tests.

In this directory: `pnpm dev`, `pnpm lint`, `pnpm format` (writes fixes), `pnpm typecheck`, `pnpm test`, `pnpm build`.

Notes:

- `src/styles/tokens.css` and `base.css` are copies of `docs/design/specimen/`; change the specimen and DESIGN.md first, then re-copy.
- `src/routeTree.gen.ts` is generated by the router plugin on `vite`/`vite build`; commit it (typecheck needs it).
- `src/api/openapi.json` and `schema.d.ts` are generated by `make api-client` from the backend (commit both; checks fail when either is stale). Call the API through `api` in `src/api/client.ts` (CSRF handled).
- Dev runs on a School's host: open http://a.localhost:5173 (the School comes from the subdomain; the proxy keeps the Host header).
- Fonts come from `@fontsource` (self-hosted, Vietnamese subset).
- Add shadcn components by hand or with `pnpm dlx shadcn@latest add <name>`; `components.json` is configured.
