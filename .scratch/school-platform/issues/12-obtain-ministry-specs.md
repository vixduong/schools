# Obtain the Ministry's current technical specifications for the education database and digital report cards

Type: task
Status: open
Blocked by:

## Question

API sync with the national education database (Circular 42/2021) and live digital report card submission (Circular 70/2026) cannot be planned without the Ministry's current specifications, which the research could not read: Decision 4998/QĐ-BGDĐT (data and technical standards) and whatever replaced Decision 3016/QĐ-BGDĐT (digital report card fields, XML, signing, API), plus the vendor connection procedure. This is a HITL task for the owner (or the pilot School). Checklist:

- [ ] Ask the pilot School to request, through its Sở GDĐT, the current digital report card specification and the database connection guide; or write to the Ministry's IT unit (Cục Khoa học, Công nghệ và Thông tin, MOET) as a software vendor.
- [ ] Obtain Decision 4998/QĐ-BGDĐT and its current amendments.
- [ ] Obtain the successor of Decision 3016/QĐ-BGDĐT (it lists an expiry of 1 Sep 2026).
- [ ] Ask how a vendor gets onto the list of conforming software, and what test or certification it requires.
- [ ] Ask whether private Schools use the same signing certificate channel as public ones.
- [ ] Get current Ministry Excel import templates for the start-of-year and end-of-year reports.
- [ ] Put every document received in `docs/external/` and record what arrived in the answer.
